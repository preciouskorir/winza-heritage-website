# Winza Heritage website

A responsive four-page static website prototype, built with HTML, CSS and vanilla JavaScript. No build step or package installation is required.

## Pages
- `index.html` — Home / brand introduction
- `collections.html` — product categories and enquiry links
- `about.html` — Director, brand story and heritage consultancy
- `contact.html` — contact details, partnerships and enquiry form

## Run locally
1. Extract the ZIP.
2. Open the `winza_heritage_site` folder in VS Code.
3. Install the free **Live Server** extension (if not installed).
4. Right-click `index.html` and select **Open with Live Server**.
5. Test every navigation link, enquiry link, WhatsApp button and the small FAQ assistant on desktop and mobile widths.

You can also double-click `index.html`, but Live Server is recommended for a more realistic local test.

For a static preview, use Netlify Drop: sign in to Netlify, open the manual deploy/Netlify Drop page, and drag the extracted `winza_heritage_site` folder (the folder containing `index.html`) into the drop area.
